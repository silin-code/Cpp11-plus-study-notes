## 三大工具模板

### 1. 差分：区间加 x，最后还原一次

```cpp
// 给 [l, r] 每个数加 x（1-based）
d[l]     += x;
d[r + 1] -= x;
// 所有操作做完后，原地前缀和还原（只做一次！）
for (int i = 1; i <= n; i++) d[i] += d[i - 1];
```

- `d[i] = a[i] - a[i-1]`，记的是**差值**
- 原数组 = 差分数组的前缀和
- 数组至少开 `n + 2`（`r + 1` 会越界）
- **右端点是否包含**决定用 `r + 1` 还是 `r`：
  - 区间 `[l, r]` 两端都算 → `d[r + 1] -= x`
  - 实际占 `[l, r-1]`（如拼车的下车点）→ `d[r] -= x`

### 2. 前缀和：区间查询 O(1)

```cpp
// 一维：pre[i] = a[1] + ... + a[i]
long long s = pre[r] - pre[l - 1];

// 二维（哨兵版，零 if）
pre[i][j] = pre[i-1][j] + pre[i][j-1] - pre[i-1][j-1] + matrix[i-1][j-1];
//                                               ↑ 这一项最常漏
long long s = pre[r2+1][c2+1] - pre[r1][c2+1] - pre[r2+1][c1] + pre[r1][c1];
```

- **需要写边界 if，说明哨兵没开**（多开一行一列全 0）
- 前缀和一律 `long long`

### 3. 二分答案：外层固定，只换 check

```cpp
int lo = 下界, hi = 上界;
while (lo < hi) {
    int mid = lo + (hi - lo) / 2;
    if (check(mid)) hi = mid;        // 可行 → 往小逼（保留 mid）
    else            lo = mid + 1;    // 不可行 → 往大逼（排除 mid）
}
return lo;
```

- **可行往小逼，不可行往大逼**（唯一要记的判定规则）
- 二分答案是"逼近边界"，不是"找目标"，**不能在循环里 `return`**
- 下界移动必须写 `lo = mid + 1`，写 `lo = mid` 会死循环

## 通用技巧与坑

| 技巧 / 坑 | 说明 |
|---|---|
| 向上取整 | `(a + b - 1) / b`，等价于 `ceil(a / b)`；**两个 int 相除是截断除法** |
| 强制转换 | `(double)a / b` 得浮点；`(double)(a / b)` 先整数除完再转，小数早丢了 |
| 哨兵 | 加法单位元 0，乘法单位元 1；把"不存在的部分"变成"值为 0/1 的合法部分" |
| 数据类型 | 前缀和、累加、计数默认 `long long`；`int` 上限约 2.1×10⁹ |
| 复杂度估算 | C++ 约 10⁸ 次操作/秒；超过就要换思路（蓝桥杯按测试点给部分分，能提前判断超时很关键） |
| `memset` | 参数顺序是 `(指针, 值, 字节数)`；只对 0 和 -1 安全；初始化建议直接 `int a[N] = {0};` |
| `INT_MAX` | 求最小值时用 `INT_MAX` + `min()`；求最大值时用 `INT_MIN`（或 0）+ `max()`，**起手值和累积函数必须配对** |
| 两种二分写法 | 逼近式（`while(lo<hi)` + `hi=mid`，本文所用）与查找式（`while(l<=r)` + `r=mid-1`，返回 `l`）；前者不易错 |
| 离散化二分 | 答案范围极大时，先收集所有候选值去重排序，在**下标**上二分；注意 `lo`/`hi` 是下标、`mid` 是值，两者不能混 |

## 错题本（反复出现的问题）

1. **递推式漏加当前元素** —— LC 304（漏 `matrix[i][j]`）、LC 974（`dp[i] += dp[i-1]` 漏 `nums[i]`）
2. **漏掉边界 / 空前缀** —— LC 974 漏 `hash[0] = 1`
3. **数组大小按「操作条数」而非「位置个数」开** —— LC 1109（`i < n`）、LC 1094（`diff(trips.size()+1)`）
4. **原地修改破坏原始数据** —— LC 1094 在循环里反复做前缀和，第二次操作全错
5. **改动只改一半** —— LC 410（`sum = e` 加了，`sum += e` 没挪进 `else`，元素被算两次）
6. **起手值与累积函数不配对** —— LC 410（`lo = INT_MAX` 配 `max()`，循环跑完什么都没变）
